# Tripistry

Tripistry is a travel comparison platform that allows travellers to browse, compare, and book travel packages from multiple agencies.

## Tech Stack
- PHP
- HTML
- CSS
- JavaScript
- SQL

## Run the Application

### 1. Download the project files

### 2. Open terminal in the project folder

Navigate to the folder containing the website files.

### 3. Start the local server

```bash
php -S localhost:8000
```

### 4. Open in browser

Go to:

```text
http://localhost:8000/pages/index.html
```
